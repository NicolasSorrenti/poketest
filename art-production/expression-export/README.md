# Neo Campus TCG — new expression exports

This is an INCREMENTAL pack. It supplements, rather than replaces, neo_campus_all_regenerated_art_2026-10-20.zip.

Contains 20 adult characters, 101 individual emotion variants, 101 full transparent WebP VN expression sprites (512x1024) and 101 smaller 280x380 face versions, both arranged under rpg-assets/characters/{id}/ folders. Original approved character identity is preserved.

The output is cut from already existing expression sheets, not new hand-drawn imagery. Some hair and jacket elements approach a column edge in the source sheet; inspect in-game before final approval.

A preview contact sheet is provided at ART_PRODUCTION/EXPRESSION_PREVIEW.jpg. Detailed asset list and output paths are in EXPRESSION_EXPORT_MANIFEST.json.
