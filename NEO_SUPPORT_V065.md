# v0.65 — Card-Flip Game and permanent face-up Prizes

Neo Genesis Card-Flip Game is enabled with the printed two-step choice: pick an opponent face-down Prize (masked), guess Energy / Trainer / Pokémon, then publicly reveal that Prize permanently. Correct guesses draw exactly two cards, with incorrect guesses preserving face-up status and no draw. Face-up Prize state survives save/load via serialized owner `prizeFaceUp` indexed state; taking a Prize updates indices even in the older automatic Prize flow. Public views reveal only the explicitly face-up Prize IDs (or global Here Comes Team Rocket! effects). CPU duel UI displays revealed Prize names. Tests cover all categories, wrong guesses, reindexing, no remaining eligible Prizes, opponent-view privacy, and replay transactions. Full match UI/browser E2E remains separate.
