# Neo Harbor RPG — Game art ZIP

**Installation:** Extract this ZIP into the repository root. It creates `rpg-assets/`, with the exact paths expected by the updated RPG UI. Commit the `rpg-assets` directory to the `main` branch and redeploy Render; open `/rpg.html`.

## Contents
- 8 character PNGs named `reina.png`, `hana.png`, `shiori.png`, `yuna.png`, `akari.png`, `camila.png`, `marina.png`, `kaede.png`.
- 2 high-resolution illustrated card shop backgrounds (day and evening).
- 6 additional JPG backgrounds for home, café, park, community center, arcade and library.
- `rpg-assets/manifest.json` with asset names, provenance and quality status.

## Quality disclosure
Reina and the card-shop interiors were available as independently generated, larger images. The seven other heroine portraits and other location images had to be extracted from generated multi-panel concept art; they are usable in the current game but **not** genuine full-resolution, independently generated production masters. The upscaled character sprites have soft transparency at the edges, not fully isolated transparent silhouettes. Please consider these placeholders pending a proper character-by-character art pass. Keep character story traits and descriptions canonical even if these temporary pictures differ.

All designs are adult, SFW characters with exaggerated fashion and layered streetwear. None are official Pokémon or Square Enix character illustrations.
