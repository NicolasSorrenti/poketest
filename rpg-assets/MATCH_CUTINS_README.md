# Neo Harbor match cut-ins

This cumulative archive adds one dramatic in-match cut-in for each currently packaged character.

Paths:
- `rpg-assets/characters/{id}/cutins/match-cutin.webp`

Characters included:
- Main cast: hana, reina, shiori, yuna, akari, camila, marina, kaede
- Guests: jun, teo, iris, elio, alma, nereo

Reference montage sheets used to derive the individual cut-ins are stored at:
- `rpg-assets/cutins/reference/main-cast-sheet.png`
- `rpg-assets/cutins/reference/guest-cast-sheet.png`
