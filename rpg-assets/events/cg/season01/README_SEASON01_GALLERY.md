# Neo Harbor season01 complete gallery package

This additive archive contains 32 event CGs for season01:
- 8 G5 situation events
- 8 first-meeting story CGs
- 8 pre-duel story CGs
- 8 social/story CGs

Each scene is provided as:
- 1920x1080 WebP full image
- 640x360 WebP gallery thumbnail

Paths:
- `rpg-assets/events/cg/season01/<id>.webp`
- `rpg-assets/events/cg/season01/thumbs/<id>.webp`

Manifest:
- `rpg-assets/events/cg/season01/season01-gallery-manifest.json`
- `rpg-assets/events/cg/season01/season01-gallery-checksums.json`

This package is repository-ready for direct extraction into the project root and commit.
