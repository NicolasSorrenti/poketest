# Neo Harbor guest expression expansion

This cumulative archive preserves all earlier art and adds six Visual-Novel style expression panels for each of the six supporting NPCs: Jun, Teo, Iris, Elio, Alma, and Nereo.

New expression set per guest character:
- neutral
- happy
- surprised
- determined
- irritated
- vulnerable

Files are stored at `rpg-assets/characters/{id}/vn-expressions/*.webp` with the original six-panel sheet at `rpg-assets/characters/{id}/reference/expression-master.webp`.

Installation: unzip at repository root and commit the `rpg-assets/` additions, or upload the cumulative ZIP through the repository's `asset-packs/` flow if the installer is updated to this exact file and checksum.
